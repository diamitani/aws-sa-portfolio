STAR Case Study

S · Situation The problem
Revenue operations teams at high-growth B2B companies were losing days per week to manual prospect research, CRM deduplication, and workflow configuration. Each new ICP required rebuilding automation from scratch across Clay, HubSpot, and n8n — with no shared state, no audit trail, and no governance layer. The result: missed pipeline, inconsistent outreach, and zero repeatability.
T · Task The objective
Design and build a production-grade, multi-agent RevOps platform that could automate the complete 6-step prospecting pipeline — from ICP definition through enrichment, research, copywriting, CRM deduplication, and sequence enrollment — with human approval at every external action and a full audit trail for compliance review.
A · Action What I built
Built on the Amazon Bedrock Mantle Runtime with four specialized Action Groups:

• n8nEngineer — compiles customized n8n workflow JSON packages per ICP configuration
• ClayEnrichment — triggers waterfall enrichment via resumable webhook pattern (Clay's resumeUrl prevents pipeline gaps on async completion)
• CRMSync — deduplicates against HubSpot, Salesforce, and Attio before any staging
• ProspectResearch — Claude 3.5 Sonnet generates PAS cold email from account pain research

State persisted to DynamoDB (PK=WORKSPACE, SK=EXECUTION), workflow artifacts encrypted in S3, auth handled via Cognito User Pool with per-tenant JWT isolation. API Gateway fronts all agent invocations with rate limiting and CORS enforcement.
R · Result Measured outcomes
6-step manual RevOps process fully automated behind a single chat interface. Workflow packages generated on-demand and stored with AES-256 encryption in S3. Zero unauthorized sends — every external action gated by an approval event in the audit log. Clay enrichment gaps eliminated via resumable webhook pattern. Evolved from internal tool → SaaS product with self-serve signup and tenant-isolated billing — zero architectural rework required because the foundation was well-architected from day one.
